# RUQI — Complete Frontend UI/UX Design Specification

## 1. PROJECT OVERVIEW

Design the complete frontend UI/UX for **رُقِيّ (RUQI)**, a premium Arabic educational platform focused on structured Arabic-language learning.

The platform must feel:

- Premium
- Professional
- Educational
- Calm
- Serious
- Modern
- Minimal Islamic
- Highly consistent
- Extremely organized
- Arabic-first
- RTL-native

The entire interface must be in **Arabic only**.

Do not introduce English UI labels, English navigation, English buttons, or English placeholder text.

The platform uses **light mode only**.

The goal is to create a polished production-quality frontend design system and complete page set, not a generic educational template.

# 4. GLOBAL VISUAL IDENTITY

# 5. DESIGN STYLE

Use a hybrid visual direction:

**Modern Educational + Premium + Minimal Islamic**

The platform should look like a modern premium educational SaaS product while maintaining a subtle Arabic/Islamic identity.

Do NOT create an old-fashioned religious website.

Do NOT overuse Islamic ornaments.

The Islamic identity must be:

- Minimal
- Elegant
- Geometric
- Subtle
- Sophisticated

Use Islamic visual elements through:

- Subtle geometric patterns
- Decorative separators
- Corner decorations
- Background patterns
- Carefully controlled framing

# 80. BUTTON SYSTEM

- Gold background
- Dark text
- Medium radius
- Text-first

Secondary button:

- Gold border
- Transparent/off-white background
- Gold text

Buttons should not be excessively rounded.

Do not use icon-heavy buttons unless necessary.

---

# 81. CARDS

Cards are not the default component for everything.

Primary structure is:

**Sections + Lists**

Use cards where they provide real value:

- Educational stages
- Months
- Statistics
- Selected profile information
- Selected dashboard components
- Top leaderboard items

Avoid turning every piece of information into a card.

---

# 82. EDUCATIONAL IMAGE STYLE

For Stage, Month, Lesson, and Exam visuals:

Use:

**Background image + subtle overlay**

Ensure Arabic text remains highly readable.

The overlay must be subtle and consistent.

---

# 83. ISLAMIC DECORATION

Use:

- Geometric patterns
- Decorative separators
- Corner ornaments
- Background motifs

These can appear together, but remain minimal.

Never allow decoration to interfere with:

- Reading
- Navigation
- Forms
- Progress
- Educational content

---

# 84. MOBILE TABLES

On mobile:

Use responsive tables.

When necessary, allow horizontal scrolling.

Do not destroy important data just to avoid scrolling.

---

# 85. MOBILE LESSON NAVIGATION

Desktop:

Collapsible lesson/content navigation.

Mobile:

Collapsible drawer opened intentionally by the user.

The drawer must occupy the screen without breaking the current content.

---

# 86. GLOBAL PAGE TRANSITIONS

Use subtle fade transitions between pages.

Keep transitions fast and professional.

---

# 87. DESIGN TOKENS

Create a consistent internal design token system for:

- Colors
- Typography
- Spacing
- Radius
- Shadows
- Borders
- Breakpoints
- Transitions

All screens must reference the same conceptual tokens.

Do not create one-off visual values for individual pages.

# 89. CONTENT DENSITY

Public pages:

- Spacious
- Editorial
- Premium

Educational pages:

- Structured
- Readable
- Focused

Teacher/Admin:

- Higher information density
- Efficient management
- Still visually consistent

Do not use the same density everywhere.

---

# 90. FINAL PRODUCT FEEL

The final design should feel like:

A premium Arabic educational platform built by a professional product design team.

It should NOT feel like:

- A generic SaaS dashboard
- A generic school website
- A traditional religious website
- A template assembled from unrelated components
- A flashy marketing landing page

The visual personality should communicate:

**علم + لغة عربية + ارتقاء + تنظيم + منافسة + احتراف**

# 91. CRITICAL PRODUCT RULES

Do not invent additional:

- Pages
- Routes
- Navigation items
- User roles
- Subscription statuses
- Support statuses
- Dashboard systems
- Features
- Product concepts
- Filters
- Analytics
- Authentication methods
- Educational content types

unless they are explicitly described in this specification.

Do not redesign the information architecture.

Do not introduce dark mode.

Do not introduce English UI.

Do not introduce LTR layouts.

Do not create unnecessary sidebars.

Do not create unnecessary cards.

Do not overuse Islamic decoration.

Do not make the interface visually noisy.

# 93. FINAL DESIGN PRINCIPLE

The most important requirement is:

**Extreme visual consistency.**

Every screen must look like it belongs to the same product.

Maintain:

- Same Gold system
- Same Off-white background
- Same typography
- Same radius
- Same spacing
- Same shadows
- Same button system
- Same form system
- Same alert system
- Same progress system
- Same visual language
- Same Arabic RTL logic

The result must be coherent from the homepage all the way to the Teacher and Admin dashboards.

Build the design as a unified product, not as independent pages.
